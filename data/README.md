# Local data folder

This folder may contain ad-hoc test assets. **Dataset browse and load filters** exclude
non-driving media (README assets, logos, generic `test.jpg` files, docs paths, and files
that do not match AV camera-frame layout when an official dataset type is selected).

Place real camera frames under a nested path such as `data/images/train/` or
`data/camera/front/` for Validate & Browse and Local ingest to pick them up.
