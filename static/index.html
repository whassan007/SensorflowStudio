📂 Dataset Configuration YAML

                
Sensorflow Studio uses the standard Ultralytics YOLO configuration format. Specify the root path, train path, val path, and class labels mapping index values to strings.

            

            

                
🚦 FHWA SSAM Safety Surrogates

                
Conflict assessment monitors vehicle trajectories to calculate metrics:

                
    
                    
  • TTC (Time-to-Collision): Time until crash if speed remains constant. Hazard threshold is < 1.5 seconds.
    • 
                    
  • PET (Post-Encroachment Time): Passage interval between two vehicles crossing the same interface area. Hazard threshold is < 5.0 seconds.
    • 
                

            

            

                
⚡ Remote Cluster Training (DGX Spark)

                
Allows routing heavy GPU execution to remote systems. Make sure you activate Tailscale, setup dependencies, and verify host resolution before executing.
